   220→### New features added
   221→- **True SDK streaming** (`src/app/api/assist/route.ts`): replaced the "await full completion then chunk at 12ms/6chars" approach with `stream: true`. Now reads the SDK's `ReadableStream` with `getReader()`, parses SSE `data:` lines via a new `parseSseChunk()` helper, and forwards real model token deltas (`choices[0].delta.content`) as they arrive. Dramatically lower TTFB — first token appears as soon as the model emits it, not after the full response is generated. Includes a robust fallback: if `stream: true` fails (non-ReadableStream return or error), it falls back to a non-streaming completion + chunked typing. The `done` SSE event now includes `streamed: true/false` so the client knows which path ran.
